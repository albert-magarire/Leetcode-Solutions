## 🚀 How to Use

### Running Java Solutions
```bash
cd solutions/java/medium/
javac Solution.java

```

### Running Python Solutions
```bash
cd solutions/python/medium/
python solution.py
```

## 💡 Solution Approach

For each problem, I focus on:
- Understanding the problem constraints and requirements
- Developing multiple approaches when possible
- Analyzing time and space complexity
- Writing clean, readable code
- Including comments for complex logic

## 🔧 Development

### Java Guidelines
- Follow Java naming conventions
- Include proper documentation comments
- Use meaningful variable names
- Handle edge cases appropriately

### Python Guidelines
- Follow PEP 8 style guide
- Use type hints where applicable
- Write docstrings for functions
- Leverage Python's built-in features
